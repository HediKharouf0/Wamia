# maker-5M-L1-adaptive-extra1M-dmax30

Replays the real Aug 25 attack on the mainnet fork (block 25829822) with a Wamia strategy holding 5M SY (discount 10–30 bp), the v1 quoter alone, no v2 guards, a zero-capital searcher backrunning every Pendle-moving trade one block later (latency 1), replaying the attack with fresh slippage bounds each time (adaptive), same SY per trade, a persistent attacker that keeps pushing 1M more SY of trades after the historical attack ends.

## Reproduce

```bash
anvil --fork-url "$ARCHIVE_RPC_URL" --fork-block-number 25829822   # separate terminal, needs contracts/ built
npm run scenario:maker -- --capital 5 --extra-attack 1 --dmax 30
```

Writes exactly the three JSON files in this folder; nothing here is hand-edited.

## Result

- Oracle min: 0.9463 (spot min 0.9463)
- Eligible debt at the worst point: $37,350,455 (USDC 13 pos / $35,463,444, USDT 7 pos / $1,887,011)
- Manipulator: 11/11 historical pushes landed, 4 of the extra pushes landed
- Wamia: 16 fills after 8 pushes, 5.00M of 5.00M SY used
- LP paid 0.9690 USD/PT, hold to maturity 11.3% annualized (fair-value buyers get 10.58%)

## Files

- `summary.json`: the numbers above, machine-readable (also rolled up into `results/maker-results.md`)
- `arbs.json`: every arb transaction the searcher sent (bought, reverted, or skipped; size, price, gas)
- `timeseries.json`: one measurement (spot, oracle, fair value, every position's health) after every block of the replay

Generated by `npm run results:readmes` from this folder's own `summary.json`.
